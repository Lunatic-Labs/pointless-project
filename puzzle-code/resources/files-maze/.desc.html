A golden robot is stuck inside a labyrinth full of winding paths, dead ends and the all important purple exit.

Example maze

The robot understands four instructions: u l d r, each of which moves it one step up, left, down, or right, respectively. So, the instructions for the example maze are uuurddruur. However, instructions written out long-hand for the real labyrinth would be tediously long. Fortunately, the robot understands run-length encoding. Make the instructions shorter by following one rule:

Any consecutive sequence of at least two letters should be replaced by the letter followed by the number of consecutive letters.

For example, uuur becomes u3r.
