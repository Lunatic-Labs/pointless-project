# Ideas and work in progress

**Nothing in this directory is part of production.** It is not compiled, tested, zipped into the game, or served by the web server. It is kept so that ideas and unfinished work are not lost.

To use something from here, move it back into `puzzle-code/` or `web-server/` and wire it up there (see the notes in each item).

| Item | What it is |
|------|------------|
| [cleanup-tasks.md](cleanup-tasks.md) | Cleanup and improvement tasks still open after the September 2026 review (decisions, web server, generator). |
| [nonogram-qr-puzzle.md](nonogram-qr-puzzle.md) | A puzzle where the player solves a nonogram that draws a QR code. Designed in 2022 (formerly GitHub issues #50, #53-55, #58, #59); never built. |
| [share-buttons.html](share-buttons.html) | Buttons for sharing the website on X/Twitter and Facebook (from the unmerged `SCRUM-share-buttons` branch, closed PR #107). The links still point at `google.com` placeholders, and the Facebook button loads Facebook's SDK. |
| [tokens-webpage-uml.jpg](tokens-webpage-uml.jpg) | User-flow diagram of the website with token submission (formerly `imgs/Pointless_UMLs-Webpage.jpg`). Drawn before tokens were built; the flow it shows now exists, but the details differ (see README "Web Server"). |
| [scrapped-based-puzzle/](scrapped-based-puzzle/) | A harder Based rematch puzzle (sorting values in made-up bases). Removed from the game; code and resources kept. |
| [beta-feedback-checklist.md](beta-feedback-checklist.md) | Checklist from a beta playtest (formerly `puzzle-code/src/dr-pepper.cbp`). Most items are done; a few are open. |
| [storyline-ideas.txt](storyline-ideas.txt) | Story ideas for tying the puzzles together (formerly `puzzle-code/html-txt/resources/storyline.txt`). No storyline is in the game. |
| [bison-pixel-art.txt](bison-pixel-art.txt) | C++ snippet that defined the bison `Image` pixel by pixel, from before the project switched from PPM to SVG (formerly `puzzle-code/html-txt/resources/bisoncode.cpb`). Not valid on its own. |
